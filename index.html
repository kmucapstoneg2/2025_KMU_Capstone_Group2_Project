🚀 CI/CD 자동 배포 데모 페이지

GitHub Actions + Self-hosted Runner 기반 자동 배포 성공

📌 프로젝트 설명

이 페이지는 GitHub 저장소에 소스 코드를 push하면, 별도의 수동 작업 없이 웹 서버에 자동으로 배포되는 CI/CD 파이프라인을 검증하기 위한 데모 페이지입니다.

최근 배포 시간:

⚙ CI/CD 파이프라인 구성

  • GitHub 저장소에 소스 코드 push
  • GitHub Actions Workflow 자동 트리거
  • Self-hosted Runner에서 Job 실행
  • 웹 서버 디렉토리로 자동 배포 (/var/www/html)

🛠 사용 기술 스택

  • GitHub Actions
  • Self-hosted Runner (Ubuntu)
  • Shell Script 기반 자동 배포
  • Apache Web Server

✅ 자동 배포 검증

본 페이지는 소스 코드 수정 후 GitHub에 push 하면 수 초 내에 웹 서버 내용이 자동으로 변경되는 것을 통해 CI/CD 파이프라인이 정상적으로 동작함을 확인할 수 있습니다.
